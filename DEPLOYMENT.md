# Deployment Readiness & Hosted Demo Architecture

> [!IMPORTANT]
> **Status: Research Demonstration Only — Not Deployed to Production**
> This application is an educational prototype intended to be run in a local or isolated staging environment for methodology review. It is not currently deployed to an external hosting service and must never be connected to real applicant data streams.

---

## 1. Hosting Architecture & Prerequisites

For future hosted demonstration (e.g. Streamlit Community Cloud, containerized staging, or internal sandbox):

### Prerequisites:
- **Operating Environment:** Linux (Ubuntu 22.04+ or Debian 12+) or container runtime (Docker / OCI).
- **Python Runtime:** Python `3.10`–`3.13` (tested locally on Python `3.13.7` and configured for Python `3.12` on `ubuntu-latest` CI runner).
- **Dependency Constraints:** The project uses version range constraints declared in `requirements.txt`:
  ```
  numpy>=2.0
  pandas>=2.0
  scikit-learn>=1.4,<1.8
  matplotlib>=3.8
  joblib>=1.3
  streamlit>=1.35
  ```
- **Port:** Default Streamlit port `8501`.

## 2. Artifact Expectations & Integrity Checks

Before starting the service, the following serialized model artifacts and schema contracts must be present in the application root:

1. **Serialized Models:**
   - `models/hybrid_logistic_regression.joblib` *(required for Streamlit and CLI inference)*
   - `models/hybrid_hist_gradient_boosting.joblib` *(benchmark artifact)*
   - `models/traditional_baseline.joblib` *(baseline artifact)*
2. **Schema & Logic Dependencies:**
   - `validation.py` (`validate_feature_frame`, `DOMAIN_BOUNDS`, `ALL_FEATURES`)
   - `inference_helper.py` (`build_applicant_row`, `run_inference_pipeline`, `load_saved_model`)
   - `risk_scoring.py` (`probability_to_score`, `map_probability_to_risk_band`)
   - `explainability.py` (`explain_logistic_prediction`)

If `models/hybrid_logistic_regression.joblib` is absent, the application halts gracefully with a clear setup notice rather than crashing. The artifact can be generated by running `python train.py`.

---

## 3. scikit-learn Serialization Compatibility

- The saved model pipelines were serialized with scikit-learn `1.7.x`.
- The project declares the dependency constraint `scikit-learn>=1.4,<1.8` in `requirements.txt`. Environments outside this range (such as unreleased scikit-learn 1.8+) have not been verified and are not claimed as supported runtime environments.
- As defensive code, the shared loader in `inference_helper.load_saved_model()` inspects and restores `classifier.multi_class = "auto"` if missing after unpickling. This guards against potential deserialization regressions during unpickling across supported releases, without asserting untested cross-version compatibility beyond the declared `<1.8` constraint.

## 4. Containerization Reference (Example Dockerfile)

For teams containerizing this prototype for internal evaluation, the following minimal pattern is recommended:

```dockerfile
FROM python:3.12-slim

# Prevent Python from writing .pyc and buffer stdout/stderr
ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1

WORKDIR /app

# Install dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir --upgrade pip && \
    pip install --no-cache-dir -r requirements.txt

# Copy application files and pre-trained models
COPY app.py inference_helper.py validation.py risk_scoring.py explainability.py ./
COPY models/ ./models/

# Expose Streamlit port
EXPOSE 8501

# Self-contained healthcheck using Python standard library (no external curl package required)
HEALTHCHECK CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8501/_stcore/health')" || exit 1

ENTRYPOINT ["streamlit", "run", "app.py", "--server.port=8501", "--server.address=0.0.0.0", "--server.headless=true"]
```

## 5. Mandatory Safety & Governance Controls

Any future deployment must preserve:
1. **Prominent Synthetic Disclaimers:** Visible warnings at the top of the interface indicating that all data, models, and scores are simulated.
2. **Runtime Domain Validation:** Never bypass `validate_feature_frame()`; inputs outside the synthetic generator support must be rejected before calling `predict_proba()`.
3. **No Commercial Underwriting Use:** Strictly prohibit the use of these scores, bands, or feature contributions for actual lending, credit rejection, pricing, or adverse action.
